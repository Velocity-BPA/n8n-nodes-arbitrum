# Automate Arbitrum Blockchain Operations with Our New n8n Community Node

We're excited to announce the release of n8n-nodes-arbitrum, a powerful new community node that brings Arbitrum blockchain automation directly into your n8n workflows!

## The Challenge: Blockchain Integration Complexity

Integrating blockchain operations into business workflows has traditionally required extensive development resources. Teams need to bridge Layer 1 and Layer 2 networks, interact with DeFi protocols, manage NFT operations, and execute smart contracts—all while maintaining security and reliability. For organizations without dedicated blockchain developers, this presents a significant barrier to Web3 adoption.

## Introducing n8n-nodes-arbitrum

Velocity BPA has developed this community node to democratize Arbitrum blockchain automation. Whether you're building DeFi dashboards, automating NFT minting workflows, monitoring smart contract events, or bridging assets between L1 and L2, this node puts powerful blockchain capabilities at your fingertips—no coding required.

## Key Features

**L1-L2 Bridging**: Seamlessly move assets between Ethereum mainnet and Arbitrum with simple workflow nodes. Automate bridging operations based on gas prices, transaction volumes, or custom business logic.

**DeFi Integration**: Connect to decentralized finance protocols on Arbitrum. Monitor liquidity pools, execute swaps, track yields, and manage positions directly from your n8n workflows.

**NFT Operations**: Mint, transfer, and query NFTs on Arbitrum's cost-effective Layer 2 network. Perfect for automated NFT campaigns, marketplace integrations, and digital asset management.

**Smart Contract Interaction**: Read from and write to smart contracts deployed on Arbitrum. Execute functions, listen for events, and integrate blockchain logic into complex automation workflows.

**Stylus WASM Support**: Take advantage of Arbitrum's innovative Stylus technology, enabling smart contracts written in Rust, C, and C++ to run alongside traditional Solidity contracts.

## Getting Started

Installation is straightforward. In your n8n instance, run:


npm install n8n-nodes-arbitrum


After installation, restart n8n, and you'll find the Arbitrum node available in your node palette. The node includes comprehensive documentation and example workflows to get you started quickly.
